# Analizador EDO (Web)

Este proyecto es una suite de herramientas analíticas para temperamentos microtonales, centrándose principalmente en Divisiones Iguales de la Octava (EDO). Permite visualizar e investigar estructuras armónicas complejas como MOS (Moments of Symmetry), matrices de Partch, diagramas de telaraña CPS (D'Alessandro) y el círculo de quintas Pitagórico / Mesotónico.

El proyecto está construido con TypeScript y Vite, lo que permite un desarrollo ultrarrápido y un despliegue optimizado. 

---

## 🚀 Instrucciones para abrir el proyecto en tu computadora

El proyecto es una aplicación web moderna. Para que funcione correctamente en tu navegador con todas sus funciones habilitadas (como módulos y recarga rápida), **no basta con hacer doble clic en el archivo HTML**. Es necesario levantar un servidor local.

### Prerrequisito (Para cualquier sistema operativo)
Asegúrate de tener instalado **Node.js** en tu computadora. Puedes descargarlo de [nodejs.org](https://nodejs.org/).

### Opción 1: Instrucciones para Mac y Linux
1. Abre la aplicación **Terminal**.
2. Navega a la carpeta de este proyecto escribiendo `cd` seguido de la ruta donde descargaste el repositorio (o arrastra la carpeta del proyecto hacia la terminal).
3. Presiona Enter.
4. *(Solo la primera vez que abras el proyecto)* Escribe **npm install** y presiona Enter para instalar las dependencias.
5. Para iniciar el proyecto, escribe **npm run dev** y presiona Enter.
6. En la terminal aparecerá una dirección, generalmente `http://localhost:5173`. Haz clic en ella (o cópiala y pégala en tu navegador como Chrome o Safari) para usar la aplicación.
7. Cuando termines de usarla, puedes detener el servidor en la terminal presionando `Control + C`.

### Opción 2: Instrucciones para Windows
1. Abre la aplicación **Símbolo del sistema (Command Prompt)** o **PowerShell**.
2. Navega a la carpeta del proyecto escribiendo `cd` seguido de la ruta donde guardaste el proyecto. Si tienes la carpeta a la vista, puedes escribir `cd ` y arrastrar la carpeta hacia la ventana.
3. *(Solo la primera vez que abras el proyecto)* Escribe **npm install** y presiona Enter para instalar las dependencias.
4. Para iniciar el proyecto, escribe **npm run dev** y presiona Enter.
5. Te aparecerá una URL como `http://localhost:5173`. Cópiate esa dirección y pegala en tu navegador de preferencia (Chrome, Edge, Firefox).
6. Para apagar el servidor, regresá a la consola de comandos y presioná `Control + C`.
